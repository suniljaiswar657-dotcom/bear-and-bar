# BEAR & BAR

Independent BEAR & BAR website project.

## Current build
- Responsive premium storefront landing page
- Distinct editorial visual direction
- Discover, story, and visit sections
- Basic age-confirmation gate (UI only; not legally sufficient identity verification)
- No alcohol checkout, delivery, payment, or sales flow enabled

## Run locally
Open `index.html` in a browser.

## Deploy on Vercel
Import this repository into Vercel. Framework preset: **Other**. Build command: leave blank. Output directory: `.`.

## Before enabling commerce
Confirm the operating jurisdiction, business address, applicable licences, product restrictions, age/identity verification requirements, and delivery rules. The current age gate is only a front-end confirmation and must not be treated as legal compliance.
